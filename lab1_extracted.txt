Lab 1 - Exploring the Dataset & Tableau Basics
You will start this lab by exploring the wine dataset and its attributes. As you review the data,
consider what types of basic visualizations you can create in Tableau and what insights each
chart might reveal.
The main goal of this lab is to help you get comfortable with creating and interpreting basic
Tableau plots—such as bar charts, histograms, maps, scatter plots, and pie charts. Focus on
building individual visualizations to better understand the data and lay the foundation for more
advanced analysis in future labs.
You can use either Tableau Desktop or Tableau Public Online. For the online version, visit
Tableau Public, then select "Create > Web Authoring" to start building visualizations in your
browser.
Dataset Overview
The wine dataset contains nearly 130,000 reviews from around the world, with information such
as country, region, variety, description, points (ratings), and price. This enables analysis of wine
characteristics, popularity, and trends across different countries and categories.
We have organized the data into several files for different analysis tasks:
Please download the datasets from Moodle and save them somewhere easy to find. You
will use these files in this and future labs.

===== PAGE 11 =====
9. Calculated Field: Rating per Dollar
A Tableau calculated field is a custom field you create by writing a formula using existing
fields in your data. This lets you perform calculations, transform data (continuous to
categorial), or create new metrics directly within Tableau, without changing your original
dataset.
On the Data panel, right-click to create a calculated field called "Rating per Dollar" with the
formula [Points]/[Price].
Use this to find high-value wines—well-rated but affordable
===== PAGE 12 =====
10. Final Touches: Rename, Annotate, and Caption
Make your charts easier to understand:
Rename each worksheet (e.g., "Map: Avg Rating by Country"). You may rename tab names
as well, which helps you distinguish different sheets when creating dashboards/stories.
Add annotations to highlight interesting insights directly on your charts (right-click →
Annotate). Focus on key trends, outliers, or notable comparisons.
Enable captions (Worksheet → Show Caption) and customize the caption to clearly explain
what each color represents, especially for charts with complex color schemes (e.g., multiple
categories, gradients, or conditional formatting) when sharing.
